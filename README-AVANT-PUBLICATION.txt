PRO’JECTEUR — VERSION 12 — MODE D’EMPLOI

CONTENU : uniquement fichiers du site, aucun devis ni facture ni document personnel autre que les mentions légales publiées avec votre accord.

IMPORTANT — HÉBERGEMENT : les conditions officielles de GitHub Pages interdisent l’usage de leur hébergement gratuit pour exploiter une entreprise en ligne ou un site principalement destiné à faciliter des transactions commerciales. Avant le lancement commercial, migrer vers un hébergeur qui autorise explicitement ce site vitrine commercial (par exemple vérifier les conditions de Cloudflare Pages ou utiliser l’hébergement inclus chez OVH si votre offre en dispose).

1. Choisir et configurer l’hébergeur autorisant l’usage commercial.
2. Dans mentions-legales.html, remplacer le bloc Hébergement (GitHub) par les coordonnées exactes du nouvel hébergeur.
3. Dans confidentialite.html, mettre à jour le nom de l’hébergeur et la description de ses traitements.
4. Publier les fichiers du site à la racine du site. Ne PAS téléverser ce README public sur le site.
5. Relier projecteur-local.fr, vérifier HTTPS et ouvrir accueil, mentions légales et confidentialité sur téléphone et ordinateur.
6. Envoyer une demande test via Formspree et confirmer sa réception.
7. Appliquer en pratique la suppression des demandes sans suite après 12 mois, y compris dans la boîte e-mail.

POINTS À VÉRIFIER : conformité de l’hébergeur, coordonnées exactes hébergeur, éventuels transferts Formspree, règles de prospection B2B, et statut TVA dans le temps. Pas de garantie juridique exhaustive.
